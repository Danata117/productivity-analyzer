# productivity-analyzer
Анализатор продуктивности

Описание: Веб-сервис, использующий нейронную сеть для оценки продуктивности пользователя на основе физиологических данных и факторов внешней среды.

Технологии:

Backend: Flask API (обработка запросов модели).

Frontend: Streamlit (интерактивный аналитический дашборд).

ML: TensorFlow.

Как запустить:

py -m pip install -r requirements.txt

py app.py

py -m streamlit run interface.py

Описание файлов:

Dataset.csv - Дата фрейм с Kaggle (на чем обучалась нейросеть) 

model_training.ipub - блокнот с обучающим кодом для нейросети

app.py — основной файл бэкенда на Flask, обеспечивающий работу API и взаимодействие с нейросетевой моделью.

interface.py — фронтенд приложения, реализованный на Streamlit, для интерактивного взаимодействия с пользователем.

productivity_deep_model.keras — сохраненная модель нейронной сети в формате Keras.

my_model_weights.weights.h5 — веса обученной модели нейронной сети.

my_model_arch.json — конфигурационный файл с архитектурой нейронной сети в формате JSON.
